## Installation

Clone the project

```bash
git clone https://github.com/yourusername/AI_Product_Description_Generator.git
```

Go to project

```bash
cd AI_Product_Description_Generator
```

Create virtual environment

```bash
python -m venv venv
```

Activate

Windows

```bash
venv\Scripts\activate
```

Linux / Mac

```bash
source venv/bin/activate
```

Install packages

```bash
pip install -r requirements.txt
```

Create .env

```
OPENAI_API_KEY=YOUR_KEY
```

Run

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
